# Resources

The tutorials and documentation that helped us along the way.

## Python and OOP

- OOPs in Python | Object Oriented Programming - Class & Object by Rishabh Mishra: [video](https://youtu.be/ecJCVJOSfcs). Where we learned object-oriented programming in Python.

## ROS 2

- [ROS2 Tutorials - ROS2 Humble For Beginners](https://www.youtube.com/playlist?list=PLLSegLrePWgJudpPUof4-nVFHGkB62Izy) by Robotics Back-End. A beginner playlist covering packages, nodes, topics, publishers and subscribers.
- [ROS 2 Humble documentation](https://docs.ros.org/en/humble/index.html). Used for installing ROS 2 and as the reference afterwards.

## Computer vision

- Detecting color with Python and OpenCV using HSV colorspace | Computer vision tutorial by Felipe Tambasco: [video](https://www.youtube.com/watch?v=aFNDh5k3SjU&t=999s). How to write the color detection code (HSV masking).

## Control

- PID Control - A brief introduction by Brian Douglas: [video](https://youtu.be/UR0hOmjaHp0). PID basics, which we used for go-to-goal in turtlesim.

## Hardware

- [TortoiseBot Hardware Assembly guide](https://github.com/rigbetellabs/tortoisebot/wiki/2.-Hardware-Assembly) by RigBetel Labs. The official steps we followed to assemble the robot.
- [TortoiseBot repository](https://github.com/rigbetellabs/tortoisebot) by RigBetel Labs. The robot's software and wiki.
